Phases land in order and are each committed, measured and manually checked before the next starts. Every phase that edits `agent-definitions/` ends with `bun run scripts/generate-embedded.ts` in `agentic-coding/` (commit the regenerated `src/workflow/embedded.generated.ts`, never hand-edit it), then a rebuild and restart of the server/TUI so running agents receive the new text. Run nothing against the real store or `~/.config/agentic-coding`/`~/.pi`: tests already preload `test/support/isolate-config-root.ts`, and the inventory script isolates itself. Checks are focused (`bun test <file>`), plus `bun run lint` and `bun run type-check` in `agentic-coding/`; the full suite belongs to the test verifier.
