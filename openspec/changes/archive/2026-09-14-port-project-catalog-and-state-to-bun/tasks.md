## 3. Mixed-runtime sole-writer cutover

- [x] 3.1 Define bounded private StateStore/Manager operations preserving required transaction boundaries without arbitrary SQL.
  - `src/server/environment/private-api.ts`: one operation per request decoded against a closed literal set (`onExcessProperty: error`), no SQL/table/column on the wire, bounded text/limit/payload schemas, and one logical unit of work per request (`setAppState`, a history insert with its retention trim, `addApp` with its definition file plus runtime row). Served in-process at `POST /api/v1/environment/private/state`, which resolves everything locally and performs no outbound request. Covered by `test/environment-private-api.test.ts` (authorization, bounds, unknown/excess-field rejection, round trips) and pinned cross-runtime by `test/environment-operations-contract.test.ts` against the Go-encoded envelopes.
- [x] 3.2 Implement Go private state/catalog client and replace direct writable DB/config ownership in migrated mode.
  - `server/pkg/environment/` implements the existing `state.Store` and `app.Manager` interfaces over the private operations, so no Go call site changed; `pkg/services/openEnvironment` selects the owner and in migrated mode opens no database handle and parses no configuration. Envelopes are pinned byte-for-byte by `server/pkg/environment/contract_test.go`; `server/pkg/services/environment_test.go` proves migrated startup succeeds where opening SQLite would fail and that one logical write reaches the authority exactly once.
- [x] 3.3 Order startup to initialize Bun state/catalog before Go and test against recursive proxy/deadlock paths.
  - Headless (`src/server-command.ts`) and TUI (`src/tui/index.tsx`) both start the Bun authority first and then the Go child with `DEVENV_ENVIRONMENT_URL`/`DEVENV_ENVIRONMENT_TOKEN`; the delegated environment target is resolved per request, so Bun can exist before the child it delegates to. The private path never calls the child (asserted with a dead delegation target in `test/environment-private-api.test.ts`), and the Go client never uses the delegated public prefix.
- [x] 3.4 Quiesce old writers, take consistent backup, switch ownership and test Go action/history writes through Bun exactly once.
  - Ownership is an explicit switch (`DEVENV_ENVIRONMENT_OWNER`, default `bun`, `go` to roll back) and the generations never run as writers together. `test/environment-cutover.test.ts` runs both real runtimes: the Go child reports configuration it can only have obtained from Bun, a Go `/api/scripts/history` write lands exactly once in the Bun-owned database, and the child holds no `state.db` handle.
- [x] 3.5 Test invalid config reload, interrupted migration, future schema and rollback preconditions.
  - Invalid reload is a bounded diagnostic that keeps the previous snapshot (`test/environment-private-api.test.ts`, Go `LoadConfig` diagnostic test); interrupted upgrade completes idempotently with a verified backup; a newer schema fails closed without modifying the database or writing a backup; the ownership switch is asserted in `test/environment-private-api.test.ts` §rollback and ownership preconditions. Rollback gate documented in `docs/environment-state-port.md` and `docs/unified-backend-api.md`.
