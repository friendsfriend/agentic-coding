## Browser authentication isolation

Dashboard authentication is bearer-only. The private fragment is validated and retained in origin-scoped session storage, never a host-wide cookie; refresh retains access without granting another loopback port a credential. APIs reject cookie-only/unauthenticated requests. Chat images use inert-template parsing and lazy authenticated streams (5 MiB/15 seconds), local blob URLs, explicit failure/retry and cancellation/object-URL cleanup on removal/`pagehide`.
